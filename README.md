
### O catálogo

`data/catalogo.json` é a fonte de verdade. Cada item traz `arquivo`, `titulo`,
`categoria`, `plataforma`, `emissor`, `data`, `horas` e `credencial`.

Para adicionar um documento:

1. Coloque o arquivo na pasta da categoria, com nome em `minusculas-com-hifens`.
2. Acrescente a entrada em `data/catalogo.json`.
3. Rode `python3 scripts/gerar-site.py`.

O passo 3 copia o catálogo para dentro do `index.html`. É o que faz a página abrir
por duplo clique: em `file://` o navegador bloqueia a leitura de arquivos externos,
então o catálogo precisa viajar junto com o HTML. Sem esse passo, o site continua
funcionando no GitHub Pages, mas não localmente.

### Logos das instituições

Cada card mostra a logo do emissor quando ela existe em `assets/logos/`, e um
monograma colorido quando não existe. Para acrescentar uma logo, salve um **PNG de
fundo transparente** com o nome do emissor em minúsculas e hifens — "EF English Live"
vira `ef-english-live.png` — e rode `python3 scripts/gerar-site.py`. O script lista
quais emissores ainda estão sem arquivo e com que nome esperá-los.

Prefira o **símbolo** da marca ao logotipo com o nome por extenso: o selo tem 22px e
o texto vira borrão nesse tamanho. As logos são exibidas sobre um ladrilho branco nos
dois temas, porque várias têm partes pretas que sumiriam no tema escuro.

Existe também uma pasta `legacy/` local, fora do controle de versão: versão anterior
deste repositório, artigos de terceiros usados como referência e material de estudo.
Nada ali é credencial nem é referenciado pelo catálogo.

### Privacidade

Este repositório é público, então documentos com dados pessoais sensíveis não entram
aqui — RG, CPF, título de eleitor, CTPS, comprovante de residência, IRPF, notas fiscais,
exames e laudos médicos, contratos e rescisões ficam em arquivo privado separado.

Os diplomas são publicados em **versão tarjada**: RG, data de nascimento, filiação e
assinaturas manuscritas foram cobertos. Os originais íntegros não estão aqui.

O `.gitignore` traz uma barreira contra commitar esse tipo de arquivo por engano, mas
ela não substitui conferir o documento antes de adicioná-lo.
